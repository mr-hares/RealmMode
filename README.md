# RealmMode
[![GPL-3.0 license](https://img.shields.io/badge/license-GPL--3.0-blue.svg?style=for-the-badge&logo=github)](https://github.com/mr-hares/RealmMode/blob/master/LICENSE) [![Modrinth](https://img.shields.io/badge/modrinth-1.21.x-green?style=for-the-badge&logo=modrinth)](https://modrinth.com/project/realm-mode) [![Issues](https://img.shields.io/github/issues/mr-hares/RealmMode?style=for-the-badge&logo=github&label=Issues)](https://github.com/mr-hares/RealmMode/issues)

**RealmMode** - это лёгкий и высокопроизводительный плагин для Minecraft, который позволяет игрокам самостоятельно выбирать между режимами **PVE** и **PVP**. Игроки переключают режим через удобное GUI-меню, а администраторы управляют настройками и статистикой с помощью команд. Плагин полностью настраивается через конфигурацию и поддерживает современные hex-цвета.

## Ключевые особенности

* **Два режима на выбор:** PVE и PVP с индивидуальными настройками для каждого режима.
* **Удобное GUI-меню:** Выбор режима, подтверждение и просмотр статистики в одном интерактивном интерфейсе.
* **Статистика режимов:** Общее количество игроков и распределение по PVE/PVP с постраничной навигацией.
* **Кулдаун на смену режима:** Защита от частого переключения режимов.
* **Уведомления и broadcast:** Оповещения о смене режима для игрока и всего сервера, а также красивые Titles.
* **HEX-цвета:** Полная поддержка формата `<#RRGGBB>` для яркого оформления сообщений.
* **Локализация:** Гибкая настройка всех сообщений через конфигурацию.

## Установка

1. Поместите `RealmMode.jar` в папку `/plugins/` вашего сервера.
2. Запустите или перезапустите сервер, чтобы сгенерировать файлы конфигурации.
3. Настройте `config.yml` под свои нужды (сообщения, кулдаун, права и т.д.).
4. Готово!

---

## Команды и права

| Команда | Описание | Право (Permission Node) |
| :--- | :--- | :--- |
| `/mode` | Возможность сменить режим | `Доступна всем` |
| `/rm reload` | Перезагружает конфигурацию плагина | `realm-mode.admin.reload` |
| `/rm change [ник] [PVE/PVP]` | Принудительно меняет режим игрока | `realm-mode.admin.change` |
| `/rm stats` | Просмотр статистики режимов | `realm-mode.admin.stats` |

> [!IMPORTANT]
> **Обычные игроки** могут менять режим через GUI-меню без дополнительных прав.

## Режимы

<td style="border: none; width: 50%; vertical-align: top; padding: 12px;">
<b>PVE - Строй, добывай, выживай</b>

Мирная игра без PVP-сражений. Идеально для строителей и исследователей: полная свобода в строительстве, добыче ресурсов и исследовании мира без риска быть атакованным другими игроками.
</td>
<td style="border: none; width: 50%; vertical-align: top; padding: 12px;">
<b>PVP - Снаряжайся, убивай, сражайся</b>
  
Полноценные сражения с другими игроками. Для тех, кто ищет азарт и соперничество: открытые бои, соревновательный дух и возможность доказать своё превосходство на поле боя.
